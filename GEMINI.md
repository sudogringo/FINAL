# GEMINI.md

This project focuses on the digital transformation of **Golden Harvest S.A.**, transitioning from a static web presence to a robust e-commerce ecosystem. The core objectives include building a transactional platform and implementing extensive automation through **n8n** to optimize marketing and logistics.

## Project Overview

- **Objective:** Implement a transactional website (Frontend/Backend) and automate business processes.
- **Key Technology:** [n8n](https://n8n.io/) for business automation.
- **Core Automation Targets:**
  - Automated marketing (abandoned carts, promotions).
  - Logistics documentation generation (shipping labels).
  - Branding color extraction and site analysis (SEO, performance).
  - Automated social media content (Instagram/WhatsApp stories).
  - Customer review management (Google Maps).
  - Monthly activity reporting and personalized newsletters.

This directory currently holds the foundational planning and academic documentation for the project.
